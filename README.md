# Data Structures Rust

This is a personal project for learning Rust. Implementing data structures from scratch is one of the best ways to understand ownership, borrowing, lifetimes and generics, so I'm working through them one at a time, mostly for fun. The code here is written by hand, not generated by AI. The point is to wrestle with the compiler myself and learn from it.

The crate will grow into a collection of data structures and algorithms I find interesting, added as I get to them. It may eventually be published on crates.io, but for now treat it as a learning project rather than a production-ready library. If you need battle-tested collections, the Rust standard library is the place to look.

Artisian code only, strict no AI policy in this repo.
